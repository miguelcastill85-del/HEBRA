# HEBRA Trust-Root Threat Tree v0.5

Objetivo del atacante: cambiar el estado confiable canónico con contenido falso.

## Ruta A — Evidencia falsa
Debe conseguir TODAS:
- 2/3 Provenance
- 2/3 Measurement
- 2/3 Methodology
- 2/3 Safety

Mínimo: 8 dominios independientes.

## Ruta B — Sustituir el Núcleo Cristal
Debe conseguir TODAS:
- 4/7 Release Guardians
- 2/3 Reproducible Builders
- 2/3 Independent Release Auditors

Mínimo: 8 dominios independientes.

## Ruta C — Abusar de recuperación de emergencia
Debe conseguir TODAS:
- 5/9 Recovery Guardians
- 3/5 Recovery Auditors

Mínimo: 8 dominios independientes.

## Ataques que deliberadamente NO bastan
- controlar sólo la IA;
- controlar sólo el servidor;
- controlar sólo GitHub;
- crear usuarios Sybil ilimitados;
- envenenar el Mar Inerte;
- controlar políticas ordinarias para intentar bajar el piso de seguridad.

## Riesgos que BTR-8 todavía NO resuelve
- un mismo fallo afecta a muchas partes supuestamente independientes;
- error en el Núcleo Cristal;
- ruptura criptográfica;
- compilador/runtime compartido malicioso;
- colusión o dependencia oculta;
- dispositivo final comprometido.

Éstos pasan a ser objetivos obligatorios de la siguiente fase.
