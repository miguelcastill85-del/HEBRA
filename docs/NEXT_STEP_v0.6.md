# Siguiente paso oficial — COMMON-MODE-001

Objetivo: estudiar fallos que podrían afectar al mismo tiempo a guardianes que parecen independientes.

Ejemplos:
- todos usan el mismo programa con el mismo error;
- todos dependen del mismo compilador;
- todos dependen de la misma biblioteca criptográfica;
- todos usan el mismo firmware o proveedor de hardware.

Regla: no declararemos resuelto un riesgo simplemente porque aumentemos el número de firmas.
