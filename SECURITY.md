# SECURITY

## Regla principal

Si descubres una vulnerabilidad, no se oculta ni se borra del historial.
Se registra, se estudia y se corrige mediante una nueva versión.

## Modelo de seguridad actual

La propiedad principal es ICC-0:

> Los datos no autorizados no deben poder cambiar el estado confiable.

Los prototipos actuales NO deben considerarse software de producción.

## Áreas todavía abiertas

- compromiso parcial de verificadores;
- robo y rotación de claves;
- recuperación después de compromiso;
- raíz de confianza distribuida;
- implementación endurecida fuera del prototipo Python;
- prueba formal más completa.
