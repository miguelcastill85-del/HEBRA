# HEBRA

**HEBRA** es un proyecto abierto para ayudar a las personas a resolver problemas de forma segura,
verificable y reutilizable.

## Explicado de forma sencilla

Internet guarda muchas opiniones. HEBRA quiere guardar algo diferente:

**qué se intentó, en qué situación, qué pasó después y qué tan confiable es el resultado.**

HEBRA no permite que un dato nuevo cambie automáticamente lo que el sistema considera confiable.
Los datos entran primero como información sin autoridad y sólo pueden pasar al núcleo confiable
cuando cumplen reglas verificables.

## Principios principales

- Ayudar a las personas primero.
- Gasto nuevo = 0 hasta que HEBRA genere ingresos propios.
- No vender datos personales.
- El dinero no compra peso de evidencia.
- Un dato no autorizado tiene influencia 0 sobre el estado confiable (ICC-0).
- La IA puede proponer, pero no puede aprobarse a sí misma.
- Todo cambio importante queda registrado.
- Siempre explicar el trabajo con palabras sencillas.

## Dónde mirar primero

1. `CANON.md` — reglas que no deben olvidarse.
2. `STATE.json` — dónde está exactamente el proyecto ahora.
3. `ROADMAP.md` — qué sigue.
4. `docs/PLAIN_LANGUAGE.md` — cómo debe explicarse cada cambio.
5. `docs/CONTINUITY.md` — cómo continuar en otra conversación o herramienta.
