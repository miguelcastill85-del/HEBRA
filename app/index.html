HEBRA

Primer piloto local — v0.9

Una herramienta para probar pequeñas soluciones sin cambiar la definición de éxito después de conocer el resultado.

Antes de comenzar

Este piloto sólo es para aprendizaje, organización y hábitos cotidianos de bajo riesgo.

No lo uses para salud, medicación, finanzas, derecho, emergencias, seguridad física ni autolesión.

HEBRA Local no envía tus respuestas a ningún servidor. El archivo contiene lo que tú escribas, por eso evita incluir datos sensibles.
